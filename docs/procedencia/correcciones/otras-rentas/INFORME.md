# Otras rentas en la reducción del trabajo: TDE-09 y TDE-10

Se implementan las dos discrepancias aceptadas con alcance limitado por la contrarrevisión de trabajo. Normas contrastadas: [Ley 39/2010, artículo 60](https://www.boe.es/eli/es/l/2010/12/22/39) y [Ley 26/2014, artículo primero.Doce](https://www.boe.es/eli/es/l/2014/11/27/26). Los originales, coordenadas y hashes constan en las citas TDE-C-ley39-2010-60-17 y TDE-C-ley26-2014-12-10 de auditoría y revisión.

En 2012–2014, superar 6.500 euros de otras rentas no exentas lleva la reducción ordinaria a 2.652 euros. Desde 2015 excluye esta reducción. La igualdad exacta conserva el régimen ordinario. La API canónica exige el saldo explícito; la API antigua sigue siendo un adaptador del perfil sin otras rentas, para conservar las reproducciones históricas y la conciliación legacy. No se ha modificado ningún informe o instrumento original de los revisores.

La liquidación calcula primero las ganancias sujetas y las suma algebraicamente al rendimiento inmobiliario simplificado. No usa una base del ahorro limitada a cero, no incluye ganancias exentas y no convierte pérdidas en cero. Las categorías que todavía no admite el contrato anual —capital mobiliario, actividades y otras— no quedan mágicamente cubiertas: cada ampliación debe conectarse de forma explícita. El alquiler sigue sin gastos ni reducciones completos; esa limitación impide presentar la suma como una renta neta universal.

Pruebas propias: quince ejercicios en la función, siete liquidaciones y tres casos de pérdidas/exención/alquiler. El primer pase produjo 22 fallos numéricos reales y tres errores de preparación por omitir el contexto obligatorio del servicio. Se conserva el log íntegro con ese nombre explícito; los tres errores no se cuentan como discrepancias fiscales. Corregida la preparación y aplicada la implementación, pasan las 25 pruebas. Junto con la reducción en su extremo y la suite anual, pasan 85 pruebas. No se suman los recuentos solapados.

Comando: `bun run test tests/otras-rentas-trabajo-procedencia.test.ts tests/reduccion-trabajo-procedencia.test.ts tests/liquidacion-irpf-anual.test.ts --maxWorkers=1`. El año 2026 se prueba como perfil técnico y no como ejercicio cerrado. Quedan pendientes otros incrementos históricos, contratos de gastos efectivos y revisión de esta integración.
