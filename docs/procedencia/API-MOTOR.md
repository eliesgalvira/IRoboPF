# API del motor para el rediseño

**En reforma.** Las firmas actuales no son un contrato de compatibilidad. La [decisión de motor único](REFORMA-MOTOR.md) autoriza sustituirlas, incluido el catálogo de deducciones.

La nueva API distinguirá hechos declarados, selección normativa por ejercicio y territorio, resultados calculados y casos no soportados. Los resultados enlazarán con su procedencia; los rechazos indicarán qué información o cobertura falta. No ofrecerá un modo legacy ni otro cálculo alternativo del mismo importe.

Todavía no se publican aquí firmas nuevas como si estuvieran implementadas. Cada integración actualizará este fichero con los tipos y exportaciones reales, ejemplos ejecutables, unidades, condiciones de admisión y cambios que afecten al rediseño. Las limitaciones pendientes seguirán visibles.

Las notas anteriores del [catálogo de deducciones](deducciones-2025/CAMBIOS-PARA-REDISENO.md) describen entregas existentes, pero no obligan a conservar su API. El rediseño debe tomar como referencia el contrato nuevo una vez integrado.

El catálogo integrado conserva las colecciones regionales, pero Comunitat Valenciana, Galicia y La Rioja ya no exponen constructores o exportaciones intermedias para cada deducción. Sus descripciones expresan las condiciones documentadas; no constituyen todavía evaluadores automáticos completos. Las 40 fichas valencianas están marcadas como pendientes de pruebas de cálculo.
