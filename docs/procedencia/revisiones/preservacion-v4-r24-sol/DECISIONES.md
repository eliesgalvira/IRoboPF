# Decisiones de la revisión independiente R24

Cada conclusión nueva queda candidata a contraste posterior. No hay fixes ni aceptación fiscal.

1. Se distingue el corte fijado de un respaldo integral del repositorio. Objeción experta: los 447 hashes tipados pueden ocultar dependencias oficiales anteriores que no entran en los siete prefijos del control. Respuesta: se reproduce ese control y se añade un barrido de todos los JSON/JSON.gz nuevos transportados; aparecen ausencias concretas INE, CARM y Cantabria. Coste: el informe no permite declarar autosuficiente todo el corpus y exige otra selección editorial antes de prometerlo.

2. Se conserva el pin externo y no se corrige el paquete. Objeción experta: aceptar un consumidor permisivo solo porque coincide una copia mezcla integridad con contrato. Respuesta: cinco expectativas protectoras permanecen rojas; se distingue su incidencia sobre futuras ediciones de la integridad del corte recibido. Coste: consumidor y schema necesitan nueva revisión después de cualquier corrección; aquí no se repara ninguno.

3. Se restaura una copia completa y se materializan todas las rutas auxiliares. Objeción experta: una muestra de hashes no demuestra que el respaldo arranque sin CAS originales. Respuesta: conjuntos exactos, dos hashes, tamaño, lstat y separación de inodos; tres PNG y textos, más un bloque HTML, se reconstruyen solo con bytes restaurados. Coste: unos 1,93 GB adicionales para restauración y metadatos, más entorno y residuos; no constituye simulación de pérdida de energía ni custodia independiente.

4. Se usa software actual identificado como herramienta. Objeción experta: ejecutar fuentes conservadas por estar hasheadas confunde conservación con confianza; comparar un JSON saneado con el original bruto inventaría cambios de software. Respuesta: lectura AST de históricos, comparación separada con sourceSha256 y sha256 transportado, registro de intérprete, módulos, paquetes y locks. Coste: no se certifica ejecutabilidad histórica desde cero ni disponibilidad futura del cierre Nix/uv. El recolector y schema v3 actuales difieren de sus fuentes R21; los helpers importados por v4 no convierten su validador propio en v3 corregido.

5. Se clasifican las omisiones de validación por efecto y alcance. Objeción experta: un Unicode aceptado, un límite no impuesto al lector o una URL privada sintética no son automáticamente una filtración del paquete real. Respuesta: cada caso conserva su reproducción, el ancla externa sigue intacta y se separan defectos de contrato, límites declarados y riesgos no demostrados. Coste: no se promete saneamiento semántico universal, normalización entre plataformas ni resistencia ante un escritor hostil.

6. Se corrigen solo errores de instrumentos propios. Objeción experta: cambiar el esperado o la fuente para obtener verde encubriría un fallo. Respuesta: se conservan el intento get_text, el StopIteration de una adquisición secundaria heredada y el primer mypy; get_textbox se deriva del productor histórico leído sin ejecutarlo, y las adquisiciones secundarias se resuelven en el manifiesto histórico preservado. Los esperados de citas y rojos no cambian. Coste: logs separados y explicación de por qué el comando inicial de restauración terminó con código 1 después de restaurar y materializar correctamente.
