# CI previo a publicar las conexiones territoriales y el ajuste histórico

Los 31 comandos de `.github/workflows/checks.yml` pasan con PATH limpio y las versiones fijadas: Node 24.20.0, Bun 1.3.13 y Python 3.13.15. Se ejecutan los pasos Nix del corpus y los comandos literales de ambos trabajos, incluidos inventario, generados y comprobación de cachés. No se emula Ubuntu ni la descarga de las acciones de instalación. [Comandos, duraciones y hashes](comandos.json).

El registro contiene 4038 ejecuciones Vitest y 247 métodos Python contados por suite, incluidas las omisiones que declare cada una. Hay solapamientos entre suites; estas cifras no se presentan como casos únicos. Tipos y lint pasan, con los 18 avisos anteriores. La validación conjunta previa del integrador tenía 1.342 pruebas; posteriormente se añadieron las 25 pruebas independientes de N1–N4 y se ejecutaron dentro de este workflow.

El primer intento local encontró 20 módulos nuevos sin entrada en el manifiesto de hashes. El empaquetador actualizaba sólo claves existentes; se incorporaron las nuevas fuentes revisadas, conservando la comprobación por contenido. Pasan las 26 regresiones del flujo y la repetición completa de los 31 comandos. En la segunda pasada apareció un alias privado en un test D51 y 40 aserciones de cuota exacta anteriores a la política Open histórica. Se corrigieron sólo imports y la selección de política de esos tests: el fixture documental y sus 40 importes permanecen intactos, contrastados con el núcleo decimal. La API se comprueba por gravámenes cuantizados y con los pilotos oficiales. Pasan 141 pruebas focales. Un tercer intento encontró un hijo del test de inventario terminado sin stderr; la causa exacta no quedó identificada. La misma prueba pasó aislada tanto en entorno de trabajo como limpio. Se redujo la memoria retenida por ese test, conservando todas sus comprobaciones y los bytes comparados, se acotó su árbol con timeout y se amplió el diagnóstico de fallos del generador. El artefacto se regeneró y se repitieron los 31 pasos. No cambió una fórmula monetaria para resolver estos fallos ni se publicaron los intentos fallidos.

El corte conecta E38, D51, C36, F y Aragón con ambas API y conserva el consumo único de cuota. C36 H1/H2 y F R1–R3 tienen contraste favorable; N1–N4 se corrigieron y recibieron contraste favorable acotado con 63 pruebas. Las reservas de cada matriz siguen vigentes. El ajuste histórico se limita al empleo efectivo de Madrid 2018–2024 observado en los siete pilotos; las capturas adicionales no cuentan como comparaciones. ELA, donativos estatales y maternidad/guardería se desarrollan por separado y aún no forman parte de esta publicación.

Destino exclusivo: `procedencia-documental`. El resultado remoto se comprobará después del push; esta evidencia es local.
