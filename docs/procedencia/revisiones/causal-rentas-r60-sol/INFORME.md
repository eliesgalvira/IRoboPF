El adaptador causal también valida el descriptor original y rechaza callbacks/observadores externos. Las obligaciones editoriales pendientes se preservan; modificarlas no concede autorización. Este replay comparte semántica con el productor: no es un oracle independiente ni autentica el host.
3. La batería recibida compara 52 entradas/520 salidas con API financiera TS real, cuatro entradas/40 salidas con expectativas racionales completas y siete condiciones/14 aserciones específicas.
