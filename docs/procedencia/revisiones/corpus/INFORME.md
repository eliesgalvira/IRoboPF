## Contrato mínimo para el puente al inventario

Una cita promovida debe referir `itemId`, hash del snapshot de inventario generado desde el código actual, ejercicio/territorio/variante, valor decimal y unidad del inventario. El verificador carga un snapshot confiable indicado por el integrador, resuelve el ID y rechaza inexistente, duplicado, snapshot obsoleto o valor/unidad distintos. El valor esperado no se toma de la cita. La transformación percent/fraction debe ser explícita, limitada y contrastada; cabeceras de tabla necesitan relación de celda y unidad con evidencia.

Las atestaciones de semántica y revisión deben resolver registros de revisión independientes, referidos al mismo item/snapshot/cita, con autor/revisor distintos y evidencia existente. Un nombre inventado en el JSON no acredita revisión. No hace falta crear un sistema criptográfico nuevo: un registro revisado por el proceso del repositorio basta, siempre que el verificador lo consuma y no acepte la afirmación de entrada como prueba.

Separar resultados `integrity`, `inventoryBinding`, `semanticReview` e `independentReview`; no devolver aceptación global mientras falte uno. Las fórmulas requieren relación con expresión/paso e interpretación normativa, las vigencias requieren intervalos y contexto. Encontrar números no valida ninguna de las dos. Puede integrarse primero adquisición/citas con aceptación deshabilitada; cerrar el encargo requiere después implementar y probar este puente sobre el inventario actual.

## Objeciones examinadas y límites

- **Red, URLs y recursos:** esquema HTTPS y host exacto rechazan sufijos engañosos, homógrafo IDN, IPv6 loopback, IP literal, puerto no permitido, usuario no vacío y fragmento. `https://@www.boe.es/a` pasa la política por userinfo vacío: endurecimiento menor, sin evasión de host demostrada. No hay resolución DNS para excluir direcciones privadas ni fijación de IP. No se ha probado rebinding real; TLS y hosts oficiales exactos limitan el riesgo, y ampliar `--allow-host` exige decisión explícita. Las redirecciones a host fuera de allowlist fallan; a otro host permitido pasan intencionalmente, sin credenciales de petición; el sexto salto falla. No imponer same-origin a todos los portales sin revisar sus redirecciones oficiales.
- **Adquisición adversarial:** HTML de error con MIME PDF/URL PDF, tamaño excesivo, cuerpo vacío, longitud truncada y encoding gzip se rechazan sin publicar índice ni dejar temporal. Timeout simulado agota tres intentos. Hay límite de socket 30 s y tiempo comprobado entre lecturas 180 s, no deadline absoluto de operación/lock. No se ejercitó slowloris real ni descarga de 64 MB. Un HTML de error 200 para recurso HTML no se distingue semánticamente de un documento; MIME/magic no son autenticación.
- **CAS e historial:** SHA-256 restringido evita traversal por nombre; SHA-512/tamaño se verifican. localPath no gobierna resolución. Historial conserva versiones previas en el test. No se revisó atacante con escritura de symlinks en el propio CAS; su directorio debe ser de confianza. Atomicidad de JSON y originales usa replace, no equivale a durabilidad fsync ni transacción conjunta. No se probó fallo eléctrico. Rebuild exige hash esperado: fuente mutable con bytes distintos falla; no restaura una versión desaparecida sin copia archivada. No se ha realizado reconstrucción nueva en red del BOE omitido.
- **PDF:** MediaBox/CropBox con desplazamiento y origen no cero, rotaciones 0/90/180/270, límites/NaN/infinito/bools de bbox, cita literal y PNG determinista probados. El recorte coincide píxel a píxel con la misma región de página completa en las cuatro rotaciones. No certifica que cualquier capa de texto corresponda semánticamente al dibujo: pueden existir texto invisible o fuentes engañosas; hace falta inspección documental. Sin texto se exige OCR, no se inventa transcripción ni bandera verificada. No hay OCR implementado. La API cite acepta página True y produce cita inválida para el esquema; CLI int y verify lo rechazan: defecto menor de validación API, añadir type(page) is int. No se halló aceptación de NaN/bool en bbox ni escritura al verificar recorte ausente.
- **Selectores y unidades:** TextQuote exacto, FragmentSelector de página y selector propio de caja son coherentes con el contrato; no se afirma viewrect estándar. Número y unidad pueden apuntar a posiciones no relacionadas: `8,50 euros; otra columna %` pasa binding percent. Se documenta como límite semántico, no como conversión válida ni prueba de cabecera. El puente debe exigir esa relación antes de aceptación. No se probó un corpus exhaustivo de fuentes, ligaduras o separadores Unicode.
- **Firma real:** BOE consolidado devuelve unsigned; BOCM devuelve trust-indeterminate, Signature is Valid y Certificate has Expired. El test real de tamper de un byte devuelve invalid. Una ampliación incremental propia con texto sin firmar sigue trust-indeterminate y su salida dice Not total document signed. No se confunde con documento autenticado: el estado ya es indeterminado y scope declara cobertura pendiente. Antes de habilitar cualquier puerta de autenticidad añadir cobertura estructurada (ByteRange y revisión cubierta); no confiar solo en regex Signature is Valid. Una salida localizada o fallo de herramienta sin frase reconocida da not-validated. Una frase válida con exit code 1 conserva trust-indeterminate: no es trusted, pero conviene registrar fallo de herramienta de forma separada. NSS y confianza histórica/revocación no quedan resueltos con `-no-ocsp`; ningún certificado caducado permite inferir por sí solo validez o invalidez histórica. No se configuraron trust stores ni red de revocación.
- **CSV/WARC/RFC3161:** comparar bytes con una URL no autentica CSV ni vincula legalmente identificador, y el resultado lo limita expresamente. No hay validación CSV real. WARC ayudaría a preservar HTML y respuestas relacionadas, con saneamiento de metadatos; no demuestra por sí mismo identidad ni vigencia. RFC3161 acreditaría existencia temporal del hash con confianza en TSA, no legalidad. Diferirlos explícitamente es admisible para este pipeline, sin llamar WARC al CAS ni sello de confianza al reloj local.
- **Fixtures:** los cinco blobs y todas las citas/manifiestos entregados pasan hashes/esquemas. Offline solo hay dos PDF íntegros; BOE-A-2025-1 tiene manifiesto/cita sin original/recorte en este subset, limitación declarada y no escondida. No se cuenta como firma comprobada independientemente aquí.
